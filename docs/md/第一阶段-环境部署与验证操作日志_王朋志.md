# **部署步骤**

先以 root 安装 XFCE 和 xrdp，再创建 pz 用户并将其加入 sudo 组。Windows 经 SSH 本地端口转发连接远程桌面。部署日志中 xrdp 和 xrdp-sesman 均为 active。

> adduser pz

> sudo apt-get update
>
> sudo apt-get install -y git ca-certificates
>
> mkdir -p ~/xiangshan

setup-tools.sh 和 setup.sh 均返回 0。后续以 pz 构建时仍找不到 java 和 clang++，按步骤 4 补齐依赖。

# **构建故障与修复记录**

以下四类故障按发生顺序排列。每项保留原始报错、修复操作和重试结果。

## **1 在 NEMU 目录执行 emu 构建**

> 失败命令 make emu EMU_TRACE=fst -j8
>
> 实际报错 make: \*\*\* No rule to make target 'emu'. Stop.

NEMU 的 Makefile 没有 emu 目标。切换到 \$NOOP_HOME 后重跑，构建开始调用 Mill 生成 RTL，随后因缺少 Java 停止。

记录：06-emu-build.log、05-emu-build-session.log。

## **2 Mill 找不到 Java**

> 实际报错 /home/pz/.cache/mill/download/0.12.3: 16: exec: java: not found
>
> make: \*\*\* \[Makefile:224: build/rtl/SimTop.sv\] Error 127
>
> 修复命令 sudo apt-get install -y openjdk-21-jdk-headless

Mill 找不到 java，RTL 尚未生成。补装后，java 和 javac 均返回 21.0.12.1；后续日志进入 RTL 生成和 Verilator 模型编译。

记录：06-emu-build-retry1.log、05-emu-build-session.log。

## **3 模型编译找不到 clang++**

> 实际报错 make\[3\]: clang++: No such file or directory
>
> make: \*\*\* \[Makefile:277: emu\] Error 2
>
> 修复命令 sudo apt-get install -y clang

此时 RTL 已生成，构建停在 C++ 模型编译。安装 clang 后重跑 make emu，最终日志记录 emu build exit status: 0。生成的 build/emu 为 261M，--help 可正常执行。

记录：06-emu-build-retry3.log、06-emu-build-retry4.log、05-emu-build-session.log。

## **4 交叉编译器前缀不匹配**

> 失败命令 make ARCH=riscv64-xs
>
> 实际报错 make: riscv64-unknown-linux-gnu-gcc: No such file or directory
>
> 修复参数 CROSS_COMPILE=riscv64-linux-gnu-

hello 默认查找 riscv64-unknown-linux-gnu-gcc，而安装的 Ubuntu 工具链使用 riscv64-linux-gnu-。指定前缀后，LD 和 OBJCOPY 生成了 .elf 与 .bin；随后运行 .bin，得到 GOOD TRAP 和退出码 0。

记录：10-hello-build.log、10-hello-build-retry1.log、11-hello-run.log、图 1。
